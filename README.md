# Vegan Eyes (Frontend)

Vegan Eyes is an intelligent ingredient scanner that analyzes recipes and food labels for vegan compatibility.

## Features

- Scan or type ingredients
- Ingredient highlighting (non-vegan + unclear)
- Spotlight Mode (interactive focus system)
- Save recipes and deeper insights
- Library system (Recent / Recipes / Deeper)
- Community feed
- Profile system

## Tech Stack

- Next.js (App Router)
- Tailwind CSS
- Supabase (auth + database coming next)

## Status
